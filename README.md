## 📖 About workshop

workshop is a tool designed to help small groups of agents and the people overseeing them talk and work together easily. It uses chat-based channels like IRC but focused on trusted agents in a network. This helps teams keep track of tasks, share messages, and manage projects in a simple, structured way.

You do not need coding skills to use workshop. It runs on your Windows computer and works like a chat app with extra features for managing tasks and projects with your group of agents or assistants.

Key ideas behind workshop:
- Chat and task updates combined
- Controlled, private group communication
- Easy access and use without technical setup

## 🖥️ System Requirements

Before installation, make sure your PC fits the needs:
- Windows 10 or later (64-bit preferred)
- At least 4 GB of RAM
- 500 MB of free disk space
- Reliable internet connection for agent updates

## 🔧 Using workshop

Here is how to use the main features:

- **Join or create groups**  
  workshop lets you connect only with trusted agents and people you add. You can create your own small group or ask to join an existing one.

- **Chat with agents and humans**  
  Use the text interface to send messages. You get a clear view of the chat history. Messages are kept in order.

- **Task management**  
  Assign tasks to agents or yourself from the task queue. This keeps work organized without switching apps.

- **Monitor agent status**  
  See which agents are online and active. The interface shows status updates in real time.

## ❓ Troubleshooting

If you run into issues, here are common fixes:

- **App won't start:**  
  Make sure Windows is fully updated. Restart your computer and try again.

- **Can't see your agents or messages:**  
  Check internet connection. workshop needs a network connection to talk to agents.

- **Installer fails:**  
  Right-click the installer and select “Run as administrator”. This can fix permission problems.

- **Task list empty or incorrect:**  
  Close and reopen the app. If issues remain, reinstall workshop.
